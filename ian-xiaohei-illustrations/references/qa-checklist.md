# QA Checklist

## 必过项

- 是 16:9 横版，背景是干净白底。
- 生成时附带了 `assets/aiko-character-sheet.png` 作为角色参考；成图没有复刻三视图版式或题字。
- Aiko 符合“蓝白机器人”识别组合和卡通大头短身比例：黑色长直发、白 T 蓝色下装、机器人袖章或挂件。
- Aiko 完成关键动作，且与她操作的局部关键物件同尺度（高度约 0.8–1.2 倍）；通常占画面约 15%-22%，绝不超过 25%。
- 主隐喻/结构占画面约 45%-60%，第一眼先读到观点，而非 Aiko 人物。
- 一张图只讲一个核心结构；简洁清爽，保留至少 35% 留白。
- 中文标注少、短、能读；橙色只用于主路径，红色只用于重点，蓝色只用于 Aiko 标志细节或补充状态。
- 没有复刻旧案例构图，而是为当前文章生成了新隐喻。

## 失败信号

出现以下情况，重生成或局部编辑：

- Aiko 缺失卡通比例、黑长直、白 T 蓝色下装、机器人细节之一，或改成写实/偶像/学生制服风格。
- Aiko 小到像图标，或大到压过主隐喻；她与局部关键物件不成比例，或人物面积超过 25%。
- Aiko 只是装饰，或机器人反而成为主角。
- 复刻角色三视图、蓝色手写签名、正侧背排版或参考图姿势。
- 左上角有“常见坑 / Workflow / 系统架构图 / 路线图”等标题。
- 画面像 PPT、课程课件、正式流程图、角色海报或儿童插画。
- 元素、箭头或节点太多；文字变成大段解释；背景有纸纹、阴影、渐变、米色或噪点。
- 真实 UI 截图、科技感界面、中文错字严重或不可读。

## 迭代方法

- IP 跑偏：重新附带角色参考图；明确“strict identity reference，ignore pose-sheet layout”；重申卡通黑长直、白 T 蓝色短裤/裙、机器人袖章和挂件。
- 人物太大：保持她与局部关键物件同尺度（0.8–1.2 倍），把她移到边缘或物件内部；先扩大主物件与主路径。
- 人物太小：把 Aiko 放大到与她正在操作的证据砖、机器入口、操作台或桥梁节点相近的尺寸；不要按整套机器或大场景来缩放。
- Aiko 太装饰：保留小比例，让她完成一个不可替代的修补、连接、递交、开门或记录动作。
- 太可爱或太幼态：保留卡通比例，但强调“观点解释图，不是角色海报或儿童插画”。
- 太 PPT：删掉标题、边框、整齐网格和过多箭头，改成手绘场景。
- 文字错：优先删减标注；错得多就重生成并减少标注数量。

## 交付判断

高质量图应让读者先在 1 秒内看懂观点隐喻，再注意到 Aiko 正在让它运转。若第一眼先看到 Aiko 的脸或服装，视为不合格。
